# Launcher fonts

The fonts named in `../launcher.toml`, shipped with their licences (the licence travels with the
font). Static TrueType files: the launcher's rasterizer reads only a variable font's default weight.

| File | Family | Licence |
|---|---|---|
| `AlfaSlabOne-Regular.ttf` | Alfa Slab One | SIL Open Font License 1.1, `AlfaSlabOne-OFL.txt` |

Without a file the launcher uses its default font (Roboto Medium, from the SDK).
